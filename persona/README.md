# Persona

Tous les personas dans un seul dossier, préfixés par domaine.

- `it_*` — équipe technique (dev, archi, sécu, devops…)
- `vrd_*` — bureau d'études VRD
- `discord_*` — gestion serveur Discord gaming/communautaire
- `trading_*` — trading systématique IA

> **À maintenir** : ce README liste les personas disponibles. À chaque ajout / suppression / renommage d'un fichier persona, **mettre à jour le tableau du domaine concerné** (nom, fichier, rôle court). Le `/party-mode` s'appuie sur cette liste pour proposer les castings.
