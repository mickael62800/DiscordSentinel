# 🤖 Coup de Coude - Design du Bot Discord (VERSION CHAOTIQUE 😈)

## 🎯 Concept

Un mini-jeu social volontairement injuste, imprévisible et addictif. Le but : créer du drama, du fun et des situations absurdes.

---

# ⚔️ Commandes principales

- `/profil`
- `/coude @user [mise]`
- `/accepter`
- `/refuser`
- `/shop`
- `/leaderboard`
- `/prime`
- `/casino`

---

# 🔁 Flow principal

## 1. Lancer un combat

- Création d’un combat en attente
- Possibilité de **provocation publique automatique**

## 2. Acceptation

- Rolls + bonus
- MAIS avec événements aléatoires chaotiques

## 3. Refus

- Perte 20% mise
- - compteur de lâcheté
- - message humiliant public

---

# 🎲 CHAOS SYSTEM (LE CŒUR DU JEU)

## 💥 Effets aléatoires (plus violents)

- Critique sauvage (5%) → x3 gains
- Esquive divine (5%) → contre-attaque automatique
- Accident débile (3%) → les deux perdent TOUTE la mise
- Glissade (2%) → l’attaquant se frappe lui-même
- Vol (3%) → le gagnant vole +20% bonus

---

# 😈 Attaques spéciales (payantes)

- Attaque surprise → pas de refus possible
- Double coup → 2 rolls
- Coup traître → ignore bonus défense

---

# 🎯 Primes sur les joueurs

Commande `/prime @user 100`

- Met une récompense sur quelqu’un
- Si quelqu’un le bat → il gagne la prime

🔥 Résultat : chasse à l’homme

---

# 🎰 Casino

Commande `/casino 50`

Résultats possibles :

- perdre
- x2
- x5
- jackpot x10 (rare)
- faillite totale (très rare 😈)

---

# 🧬 Classes (déséquilibrées volontairement)

- Bourrin → énorme dégâts mais fragile
- Agile → quasi intouchable mais faible
- Fourbe → manipule les règles
- Tank → lent mais résistant

👉 pas équilibré = plus fun

---

# 🛒 Boutique CHAOS

## Objets absurdes

- 🧨 Explosion → les deux perdent
- 🎭 Inversion → échange des coins avec l’adversaire
- 🧠 Mindgame → voit le roll adverse avant
- 🔥 Rage → +50 attaque mais -50 défense

---

# 🐔 Système de lâcheté

- Refus répétés → rôle "🐔 Lâche"
- Les joueurs lâches :
  - gagnent moins
  - sont ciblables plus facilement

---

# 👑 Événements serveur

De temps en temps :

- ⚡ Happy Hour → gains x2
- 🩸 Bloodbath → tout le monde peut attaquer sans refus
- 🎁 Drop → distribution aléatoire de coins

---

# 🏆 Leaderboard CHAOTIQUE

Pas seulement les riches :

- plus gros voleur
- plus lâche
- plus malchanceux
- roi du chaos

---

# 🔥 Boucle de jeu

1. gagner des coins
2. les perdre stupidement
3. se venger
4. créer du drama
5. recommencer

---

# ⚠️ Philosophie

- injuste = fun
- imprévisible = addictif
- social = vivant

---

# 🚀 Objectif

Créer un jeu où :

- personne n’est safe
- tout peut arriver
- les gens parlent du bot

👉 Si les gens râlent mais continuent à jouer → t’as gagné.
