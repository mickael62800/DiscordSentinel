# Game Design Document

# Partie 4 – Les Capitaux (Ressources)

---

# 1. Objectif

Les capitaux représentent les ressources qu'un joueur peut accumuler, perdre ou utiliser.

Ils définissent les moyens dont dispose un joueur pour agir sur le monde.

Contrairement aux RPG classiques, aucun capital n'est suffisant à lui seul pour gagner.

La puissance naît de leur combinaison.

---

# 2. Philosophie

Influence repose sur une idée simple :

> **Le pouvoir prend plusieurs formes.**

L'argent est un pouvoir.

La réputation est un pouvoir.

L'information est un pouvoir.

Le réseau est un pouvoir.

Le jeu consiste à transformer un capital en un autre.

Par exemple :

Argent → Publicité → Réputation → Influence → Pouvoir politique

---

# 3. L'Influence

## Définition

L'influence représente la capacité d'un joueur à peser sur la société.

C'est la ressource centrale du jeu.

---

## Elle permet

* peser davantage lors de certains votes ;
* proposer certaines réformes ;
* attirer plus facilement des membres ;
* débloquer certaines fonctions ;
* gagner naturellement en visibilité.

---

## On gagne de l'influence en

* remportant des élections ;
* dirigeant une organisation importante ;
* accomplissant des actions remarquables ;
* participant à des événements majeurs ;
* obtenant le soutien d'autres joueurs.

---

## On perd de l'influence

* après un scandale ;
* lors d'une défaite politique ;
* en abandonnant ses responsabilités ;
* lorsqu'une organisation disparaît.

---

# 4. L'Argent

## Définition

L'argent représente les ressources financières disponibles.

Il ne constitue jamais une condition de victoire.

---

## Utilisations

Financer :

* campagnes politiques ;
* publicité ;
* événements ;
* organisations ;
* entreprises ;
* recherches ;
* recrutement.

L'argent ouvre des possibilités.

Il ne crée pas directement du pouvoir.

---

# 5. La Réputation

## Définition

La réputation représente l'image publique d'un joueur.

Elle influence la confiance que les autres lui accordent.

---

## Une réputation peut être

* excellente ;
* bonne ;
* neutre ;
* mauvaise ;
* désastreuse.

Elle évolue selon les actions du joueur et les informations rendues publiques.

Une bonne réputation facilite les alliances.

Une mauvaise réputation complique toutes les relations.

---

# 6. L'Information

## Définition

L'information est une ressource.

Elle peut être :

* publique ;
* privée ;
* secrète.

Certaines informations ont énormément de valeur.

Exemples :

* preuve de corruption ;
* projet de fusion ;
* stratégie politique ;
* enquête confidentielle.

L'information peut être :

* vendue ;
* conservée ;
* révélée ;
* falsifiée.

---

# 7. Le Réseau

Le réseau représente les relations construites avec les autres joueurs.

Ce n'est pas un chiffre.

C'est un ensemble de liens.

Par exemple :

* partenaires ;
* alliés ;
* investisseurs ;
* anciens collègues ;
* adversaires.

Le réseau devient progressivement l'une des ressources les plus puissantes.

---

# 8. Le Temps

Le temps est volontairement limité.

Chaque joueur dispose d'un nombre réduit d'actions importantes.

Cette limitation force les joueurs à :

* choisir ;
* planifier ;
* déléguer ;
* coopérer.

Le spam de commandes n'est jamais récompensé.

---

# 9. Les Capitaux des organisations

Les organisations possèdent également leurs propres ressources.

Par exemple :

* trésorerie ;
* réputation ;
* influence ;
* membres ;
* patrimoine ;
* archives.

Une organisation devient progressivement un acteur indépendant.

---

# 10. Conversion des capitaux

Le cœur du gameplay repose sur les conversions.

Exemples :

Argent
→ publicité
→ réputation

Réputation
→ nouveaux membres

Nouveaux membres
→ influence politique

Information
→ scandale

Scandale
→ perte de réputation

Perte de réputation
→ défaite électorale

Le jeu devient une chaîne de conséquences.

---

# 11. Aucun capital n'est absolu

Chaque capital possède une faiblesse.

### Argent

Ne permet pas d'acheter directement la confiance.

---

### Influence

Peut disparaître rapidement.

---

### Réputation

Peut être détruite par un scandale.

---

### Information

Perd sa valeur lorsqu'elle devient publique.

---

### Réseau

Demande du temps à construire.

---

# 12. Équilibre recherché

Le jeu doit permettre toutes les trajectoires.

Un joueur peut réussir grâce :

* à son argent ;
* à son talent politique ;
* à ses entreprises ;
* à ses relations ;
* à ses enquêtes ;
* à sa communication.

Il ne doit jamais exister une stratégie dominante.

Chaque forme de pouvoir doit pouvoir battre une autre.

---

# 13. Philosophie

Le véritable objectif du joueur n'est pas d'accumuler des ressources.

Il est de transformer intelligemment ses capitaux pour obtenir davantage d'influence.

Le joueur ne gagne pas parce qu'il possède beaucoup.

Il gagne parce qu'il sait utiliser ce qu'il possède mieux que les autres.
