# Game Design Document

# Partie 2 – Boucle de Gameplay

---

# 1. Objectif de cette section

Définir ce que fait un joueur lorsqu'il joue.

Une bonne boucle de gameplay doit répondre à une question simple :

> **Pourquoi un joueur revient-il demain ?**

Le jeu doit créer un sentiment permanent de curiosité.

Chaque connexion doit donner l'impression que le monde a continué sans lui.

---

# 2. La boucle principale

Le gameplay repose sur une succession d'étapes simples.

```
Observer
    ↓
Analyser
    ↓
Discuter
    ↓
Décider
    ↓
Agir
    ↓
Conséquences
    ↓
Le monde évolue
    ↓
Observer...
```

Cette boucle se répète continuellement.

---

# 3. Étape 1 — Observer

En arrivant sur le serveur, le joueur découvre ce qui s'est passé depuis sa dernière connexion.

Exemples :

* une entreprise a été créée ;
* un journal a publié une enquête ;
* un ministre a démissionné ;
* une loi est proposée ;
* une organisation recrute ;
* une manifestation est annoncée ;
* un scandale éclate.

Le joueur commence toujours par prendre connaissance du monde.

Le bot doit donc produire un véritable fil d'actualité.

---

# 4. Étape 2 — Analyser

Le joueur réfléchit.

Il se pose des questions.

Exemples :

* Cette loi est-elle bonne pour mon organisation ?
* Qui a intérêt à publier cette information ?
* Dois-je soutenir ce candidat ?
* Mon alliance est-elle encore fiable ?
* Un concurrent devient-il trop puissant ?

Cette phase est essentielle.

Le jeu récompense la réflexion avant l'action.

---

# 5. Étape 3 — Discuter

Le joueur échange avec les autres.

Cette étape est le cœur du jeu.

Il peut :

* convaincre ;
* négocier ;
* promettre ;
* recruter ;
* manipuler ;
* menacer ;
* organiser une stratégie.

Aucune commande Discord ne peut remplacer cette phase.

Les discussions font partie du gameplay.

---

# 6. Étape 4 — Décider

Une fois sa stratégie définie, le joueur choisit ses actions.

Exemples :

* rejoindre une organisation ;
* financer une campagne ;
* publier un article ;
* voter ;
* lancer une enquête ;
* recruter un membre ;
* proposer une loi ;
* investir dans une entreprise.

Les actions disponibles sont limitées.

Le joueur doit donc faire des choix.

---

# 7. Étape 5 — Agir

Le joueur utilise le bot.

Les commandes représentent uniquement l'exécution de ses décisions.

Le gameplay ne repose pas sur le nombre de commandes, mais sur leur importance.

Une seule action peut avoir des conséquences pendant plusieurs jours.

---

# 8. Étape 6 — Conséquences

Chaque action produit des réactions.

Exemples :

* un joueur rejoint une organisation ;
* un média répond à une accusation ;
* une manifestation est organisée ;
* une entreprise perd des investisseurs ;
* une loi est rejetée.

Les autres joueurs réagissent.

Une nouvelle boucle commence.

---

# 9. Les différentes échelles de temps

## Quelques minutes

* lire les actualités ;
* discuter ;
* effectuer quelques actions.

---

## Une journée

* suivre les événements ;
* négocier ;
* participer aux votes ;
* développer son organisation.

---

## Une semaine

* campagnes électorales ;
* grands projets ;
* alliances ;
* enquêtes.

---

## Une saison

* évolution du serveur ;
* apparition de nouvelles organisations ;
* crises majeures ;
* changement des équilibres politiques.

---

# 10. Temps de jeu souhaité

## Joueur occasionnel

5 à 10 minutes par jour.

Il peut suivre l'actualité et participer aux événements.

---

## Joueur actif

20 à 40 minutes.

Il dirige une organisation, participe aux discussions et influence les décisions.

---

## Joueur très investi

Aucune limite.

Il anime naturellement le serveur en créant des événements, en recrutant et en développant sa stratégie.

Le jeu ne doit jamais obliger les joueurs à rester connectés plusieurs heures.

---

# 11. Les objectifs quotidiens

Chaque connexion doit donner au moins une raison d'agir.

Exemples :

* un vote important ;
* une enquête ;
* une opportunité économique ;
* un recrutement ;
* un événement mondial ;
* une nouvelle loi.

Le joueur ne doit jamais se connecter pour ne rien faire.

---

# 12. Les objectifs à long terme

Au fil des semaines, le joueur cherche à :

* construire sa réputation ;
* développer son organisation ;
* obtenir du pouvoir ;
* influencer la politique du serveur ;
* laisser une trace durable dans l'histoire du monde.

Le jeu récompense davantage la stratégie que la répétition d'actions.

---

# 13. Philosophie de la boucle

Le joueur ne revient pas pour récupérer une récompense quotidienne.

Il revient parce qu'il a peur de manquer quelque chose.

Une élection.

Une trahison.

Une révolution.

Une nouvelle alliance.

Un scandale.

Le moteur principal du jeu est le **FOMO** ("Fear Of Missing Out") : le monde évolue en permanence et les décisions des autres joueurs peuvent avoir des conséquences importantes en son absence.
