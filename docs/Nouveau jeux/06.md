# Game Design Document

# Partie 6 – Le Système Politique

---

# 1. Vision

Le système politique est le moteur des décisions collectives.

Il ne sert pas à donner tous les pouvoirs à quelques joueurs.

Il sert à créer des débats, des compromis, des campagnes et des conflits.

La politique est un moyen de faire évoluer la société du serveur.

---

# 2. Objectifs

Le système politique doit permettre aux joueurs de :

* proposer des changements ;
* défendre leurs idées ;
* convaincre les autres ;
* voter ;
* gouverner temporairement ;
* être remplacés.

Le pouvoir politique est toujours temporaire.

---

# 3. Les institutions

Le monde est organisé autour de plusieurs institutions.

## Le Parlement

Le Parlement représente les citoyens.

Il est responsable de :

* voter les lois ;
* approuver certains budgets ;
* contrôler le gouvernement ;
* lancer des enquêtes parlementaires.

Le Parlement est le cœur de la vie politique.

---

## Le Gouvernement

Le Gouvernement applique les lois.

Il ne crée pas seul les règles.

Ses missions peuvent être :

* proposer des réformes ;
* gérer les événements publics ;
* lancer certains projets nationaux ;
* administrer les services publics.

Le Gouvernement reste soumis au Parlement.

---

## La Justice

La Justice veille au respect des règles.

Elle intervient lors de :

* conflits entre organisations ;
* contestations ;
* fraudes électorales ;
* violations des lois du jeu.

Son objectif est de préserver l'équilibre.

---

# 4. Les élections

Les élections sont régulières.

Avant chaque scrutin :

* les candidats se déclarent ;
* les partis font campagne ;
* les médias publient des débats ;
* les citoyens discutent.

Le résultat dépend des votes des joueurs.

---

# 5. Les campagnes

Une campagne est une période où un candidat peut :

* publier son programme ;
* participer à des débats ;
* organiser des meetings ;
* acheter de la publicité ;
* recevoir des soutiens.

Les campagnes deviennent un véritable événement communautaire.

---

# 6. Les lois

Une loi modifie une règle du monde.

Exemples :

* modifier les impôts ;
* réglementer les organisations ;
* financer un projet ;
* limiter certaines pratiques ;
* créer une nouvelle institution.

Chaque loi possède :

* un titre ;
* une description ;
* ses conséquences ;
* une durée éventuelle.

---

# 7. Proposition d'une loi

Une proposition suit plusieurs étapes.

1. Dépôt.

2. Débat.

3. Amendements.

4. Vote.

5. Application automatique par le bot.

Chaque étape possède une durée configurable.

---

# 8. Les amendements

Avant le vote final, les joueurs peuvent proposer des modifications.

Une loi évolue donc pendant les débats.

Cela encourage la négociation plutôt que le simple affrontement.

---

# 9. Les votes

Selon les lois en vigueur, un vote peut être :

* public ;
* secret.

Il peut demander :

* majorité simple ;
* majorité absolue ;
* majorité qualifiée.

Ces règles peuvent elles-mêmes évoluer.

---

# 10. La Constitution

La Constitution définit les règles fondamentales.

Exemples :

* durée des mandats ;
* nombre de représentants ;
* pouvoirs des institutions ;
* droits fondamentaux des citoyens.

La Constitution est plus difficile à modifier qu'une loi ordinaire.

Elle nécessite une procédure spéciale.

---

# 11. Les mandats

Tous les postes politiques possèdent une durée limitée.

À la fin d'un mandat :

* nouvelles élections ;
* renouvellement ;
* alternance.

Le pouvoir ne peut jamais devenir permanent.

---

# 12. Les motions

Les représentants peuvent déposer différentes motions.

Exemples :

* motion de défiance ;
* motion d'urgence ;
* création d'une commission d'enquête ;
* vote exceptionnel.

Ces mécanismes permettent de réagir rapidement aux crises.

---

# 13. Les commissions d'enquête

Le Parlement peut ouvrir une enquête officielle.

Objectifs :

* entendre des témoins ;
* demander des preuves ;
* publier un rapport ;
* recommander des sanctions.

Les enquêtes deviennent de véritables événements pour le serveur.

---

# 14. Les crises politiques

Le système doit accepter les crises.

Exemples :

* gouvernement minoritaire ;
* scandale ;
* dissolution ;
* élections anticipées ;
* manifestations.

Les crises créent du contenu.

Elles ne sont pas des bugs du système.

---

# 15. Équilibre

Le pouvoir est réparti.

Le Gouvernement propose.

Le Parlement décide.

La Justice arbitre.

Les médias informent.

Les organisations influencent.

Aucun acteur ne contrôle seul le monde.

---

# 16. Philosophie

La politique n'est pas un mini-jeu.

Elle est le mécanisme qui permet aux joueurs de transformer durablement leur serveur.

Chaque élection, chaque débat et chaque loi doit donner aux joueurs l'impression que leurs décisions ont réellement modifié le monde.

Le système politique n'a pas pour objectif de désigner un gagnant.

Il a pour objectif de produire des histoires, des conflits et des souvenirs que la communauté continuera de raconter plusieurs saisons plus tard.
