# Game Design Document

# Partie 1 – Vision du jeu

**Projet :** Influence *(nom provisoire)*

**Version :** 1.0

---

# 1. Vision

## Elevator Pitch

**Influence** est un jeu de stratégie sociale persistant conçu exclusivement pour Discord.

Les joueurs y construisent leur réputation, créent des organisations, nouent des alliances, manipulent l'information et cherchent à contrôler les décisions qui façonnent la société du serveur.

Le jeu ne possède pas de scénario prédéfini.

Le bot fournit uniquement les règles.

L'histoire est entièrement écrite par les joueurs.

---

# 2. Vision à long terme

Créer un jeu capable de transformer un simple serveur Discord en une société vivante.

Le serveur ne doit plus être uniquement un espace de discussion.

Il devient un monde où :

* des organisations apparaissent ;
* des rivalités naissent ;
* des gouvernements se forment ;
* des médias publient des enquêtes ;
* des scandales éclatent ;
* des alliances se créent puis se brisent.

Chaque communauté doit développer sa propre histoire.

Deux serveurs utilisant le bot ne doivent jamais évoluer de la même manière.

---

# 3. Le fantasme du joueur

Le joueur ne rêve pas d'être niveau 100.

Il rêve de pouvoir dire :

> "Cette entreprise, c'est moi qui l'ai fondée."

> "C'est mon parti qui dirige actuellement le serveur."

> "J'ai renversé le gouvernement."

> "Mon journal a révélé le plus grand scandale de la saison."

> "Toute la communauté connaît mon nom."

Le sentiment recherché est celui d'avoir marqué durablement l'histoire du serveur.

---

# 4. Les piliers du jeu

## Pilier 1 — Les joueurs créent le contenu

Le bot ne crée pas d'histoires.

Il crée des opportunités.

Les événements importants proviennent toujours des décisions des joueurs.

Exemples :

* création d'une entreprise ;
* élection d'un président ;
* fusion de deux organisations ;
* trahison politique ;
* fuite d'informations ;
* révolution.

---

## Pilier 2 — La communication est une mécanique de jeu

Dans Influence, discuter est une action de gameplay.

Les joueurs doivent :

* convaincre ;
* négocier ;
* recruter ;
* menacer ;
* manipuler ;
* défendre leurs intérêts.

Discord n'est pas uniquement le support du jeu.

Discord EST le terrain de jeu.

---

## Pilier 3 — Le pouvoir avant la richesse

L'argent n'est jamais une fin.

Il constitue uniquement un outil.

Le véritable objectif est d'obtenir du pouvoir.

Le pouvoir permet :

* d'influencer les autres ;
* de faire adopter des lois ;
* de contrôler des organisations ;
* d'orienter l'économie ;
* de modifier le fonctionnement du serveur.

---

## Pilier 4 — Chaque serveur possède sa propre histoire

Aucun scénario n'est imposé.

Le système doit permettre l'apparition naturelle de :

* héros ;
* criminels ;
* grandes entreprises ;
* gouvernements ;
* crises ;
* guerres économiques ;
* révolutions.

Le bot agit comme un moteur de simulation.

---

## Pilier 5 — Le pouvoir doit rester instable

Aucun joueur ne doit devenir définitivement intouchable.

Toute montée en puissance doit créer davantage de risques.

Plus un joueur possède de pouvoir :

* plus il attire les ennemis ;
* plus il devient surveillé ;
* plus il devient vulnérable aux complots.

Le jeu doit constamment produire un nouvel équilibre.

---

## Pilier 6 — Le monde continue d'exister

Le serveur ne s'arrête jamais.

Même lorsqu'un joueur est absent :

* des élections ont lieu ;
* des organisations évoluent ;
* des entreprises prospèrent ou disparaissent ;
* des événements modifient le monde.

Le joueur doit avoir envie de revenir pour découvrir ce qui s'est passé.

---

# 5. Les émotions recherchées

Le jeu cherche à produire :

## Ambition

Le joueur veut devenir une personnalité importante.

---

## Fierté

Le joueur est fier de ce qu'il construit.

---

## Tension

Chaque décision comporte un risque.

---

## Méfiance

Personne ne connaît réellement les intentions des autres.

---

## Satisfaction

Les plans élaborés sur plusieurs jours doivent être récompensés.

---

## Surprise

Les retournements de situation doivent être fréquents.

---

## Attachement

Le joueur doit développer un véritable sentiment d'appartenance à son organisation.

---

# 6. Ce que le jeu n'est pas

Influence n'est pas :

* un MMORPG ;
* un idle game ;
* un clicker ;
* un jeu de farming ;
* un simulateur économique classique ;
* un jeu principalement basé sur le hasard.

Toutes les mécaniques doivent encourager les interactions humaines.

---

# 7. Philosophie de conception

Chaque fonctionnalité ajoutée au jeu doit répondre positivement aux questions suivantes :

* Encourage-t-elle les interactions entre joueurs ?
* Génère-t-elle des histoires intéressantes ?
* Crée-t-elle des choix stratégiques ?
* Favorise-t-elle les discussions sur Discord ?
* Produit-elle naturellement des alliances ou des conflits ?

Si la réponse est non, cette fonctionnalité doit être repensée.

---

# 8. Rôle du bot

Le bot est un arbitre.

Il ne joue pas contre les joueurs.

Ses responsabilités sont :

* appliquer les règles ;
* conserver l'historique du monde ;
* gérer les organisations ;
* automatiser les systèmes politiques ;
* distribuer les informations ;
* gérer les permissions Discord ;
* déclencher occasionnellement des événements mondiaux.

Les événements générés par le bot ne doivent représenter qu'une faible partie de l'activité.

L'immense majorité de l'histoire doit provenir des joueurs.

---

# 9. Définition du succès

Le projet sera considéré comme réussi si :

* les joueurs discutent du jeu même sans utiliser de commandes ;
* des alliances se créent naturellement ;
* des organisations recrutent activement ;
* les élections provoquent de véritables campagnes ;
* les joueurs racontent les événements passés du serveur comme de véritables souvenirs.

Le succès du jeu ne se mesure pas au nombre de commandes exécutées, mais aux histoires que les joueurs racontent après y avoir joué.
