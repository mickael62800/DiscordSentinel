# Game Design Document

# Partie 3 – Les Joueurs

---

# 1. Objectif

Le joueur est l'unité fondamentale du jeu.

Toutes les mécaniques, organisations, lois et événements gravitent autour des joueurs.

Le jeu ne cherche pas à faire progresser un personnage de niveau 1 à 100.

Il cherche à faire évoluer un individu dans une société.

---

# 2. Création du joueur

Lors de sa première connexion, le joueur devient automatiquement un **citoyen**.

Il ne choisit pas de classe.

Il ne choisit pas de métier.

Il ne choisit pas de faction.

Il entre simplement dans le monde.

Tous les joueurs commencent avec les mêmes opportunités.

Leur avenir dépend uniquement de leurs décisions.

---

# 3. L'identité d'un joueur

Chaque joueur possède une identité publique.

Cette identité évolue avec le temps.

Elle est composée de plusieurs éléments.

## Informations publiques

* Nom Discord
* Date d'arrivée
* Organisations actuelles
* Fonctions occupées
* Réputation publique
* Historique des fonctions importantes

Tout le monde peut consulter ces informations.

---

## Informations privées

Certaines informations restent secrètes.

Par exemple :

* alliances cachées
* opérations en préparation
* organisations secrètes
* enquêtes en cours
* informations confidentielles

Ces informations ne sont visibles que par les personnes concernées.

---

# 4. Le profil du joueur

Le profil représente la carrière d'un joueur.

Exemple :

```
Nom : Alice

Statut : Sénatrice

Organisation :
Parti Horizon

Anciennes fonctions :
- Journaliste
- Ministre de l'Économie

Influence :
★★★★☆

Réputation :
Positive

Date d'arrivée :
Il y a 7 mois
```

Le profil raconte une histoire.

---

# 5. Les rôles

Les rôles ne sont pas des classes.

Ils représentent la place actuelle du joueur dans la société.

Exemples :

* Citoyen
* Entrepreneur
* Journaliste
* Directeur
* Député
* Ministre
* Président
* Juge
* Policier
* Syndicaliste
* Banquier

Un joueur peut changer plusieurs fois de rôle durant sa carrière.

---

# 6. Les objectifs personnels

Le jeu ne fixe pas d'objectif unique.

Chaque joueur choisit le sien.

Exemples :

Créer la plus grande entreprise.

Diriger le gouvernement.

Contrôler les médias.

Construire un immense parti politique.

Créer une mafia.

Devenir le journaliste le plus respecté.

Faire tomber un gouvernement.

Le jeu doit permettre plusieurs façons de réussir.

---

# 7. Les relations

Chaque joueur construit progressivement un réseau.

Ces relations peuvent être :

* allié
* rival
* partenaire
* ennemi
* mentor
* ancien collègue

Le bot ne décide pas de ces relations.

Elles naissent naturellement.

Certaines mécaniques viendront simplement les renforcer.

---

# 8. Les droits fondamentaux

Chaque joueur possède des droits.

Par défaut, il peut :

* créer des propositions
* rejoindre une organisation
* voter
* communiquer
* commercer
* participer aux événements

Ces droits peuvent évoluer selon les lois votées.

---

# 9. Les responsabilités

Le pouvoir apporte des responsabilités.

Un joueur dirigeant une organisation devient responsable de ses décisions.

Un élu est jugé par ses électeurs.

Un journaliste engage sa crédibilité.

Un chef d'entreprise engage la réputation de son organisation.

Le statut social devient une véritable ressource.

---

# 10. La réputation

Chaque joueur construit une réputation.

Cette réputation n'est pas simplement un chiffre.

Elle est constituée de plusieurs dimensions.

Par exemple :

* Fiabilité
* Popularité
* Influence
* Transparence
* Notoriété

Un joueur peut être :

Très connu mais détesté.

Très respecté mais peu célèbre.

Très influent mais discret.

Le jeu doit permettre ces situations.

---

# 11. La progression

La progression ne repose pas sur l'expérience.

Elle repose sur les réalisations.

Le joueur progresse lorsqu'il :

* crée quelque chose ;
* influence des décisions ;
* fonde une organisation ;
* participe à un événement majeur ;
* laisse une trace dans l'histoire.

Le monde se souvient de ses actions.

---

# 12. La mort du personnage

Il n'existe pas de mort.

Il n'existe pas de suppression du personnage.

Un joueur peut perdre :

* son pouvoir ;
* son argent ;
* son influence ;
* son mandat.

Mais son histoire reste inscrite dans les archives.

Même plusieurs saisons plus tard, les nouveaux joueurs pourront découvrir les anciens dirigeants, les grands entrepreneurs ou les responsables des plus grands scandales.

---

# 13. Philosophie de conception

Le joueur n'incarne pas un héros.

Il incarne un membre d'une société.

Le but du jeu est de lui donner les outils pour construire sa propre carrière, son propre réseau et sa propre histoire.

Deux joueurs ayant commencé le même jour doivent pouvoir suivre des trajectoires totalement différentes, simplement grâce à leurs choix et à leurs interactions avec les autres.
