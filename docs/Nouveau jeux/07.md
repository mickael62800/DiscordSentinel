# Game Design Document

# Partie 7 – L'Information

---

# 1. Vision

L'information est une ressource.

Elle possède une valeur.

Elle peut être :

* créée ;
* découverte ;
* cachée ;
* vendue ;
* achetée ;
* falsifiée ;
* révélée.

Dans Influence, contrôler l'information est souvent plus puissant que contrôler l'argent.

---

# 2. Les types d'information

Toutes les informations n'ont pas la même valeur.

Le jeu distingue plusieurs catégories.

## Information publique

Accessible à tous.

Exemples :

* résultats des élections ;
* lois ;
* annonces officielles ;
* création d'une organisation.

---

## Information privée

Connue uniquement par certaines personnes.

Exemples :

* stratégie d'une entreprise ;
* discussions internes ;
* budget confidentiel.

---

## Information secrète

Personne ne connaît son existence.

Exemples :

* identité d'un espion ;
* corruption ;
* documents cachés ;
* projet de coup politique.

---

# 3. La valeur d'une information

Une information possède une valeur.

Elle dépend de plusieurs facteurs.

* rareté ;
* crédibilité ;
* importance ;
* actualité.

Plus une information est rare, plus elle devient précieuse.

---

# 4. Les sources

Toute information possède une origine.

Par exemple :

* témoin ;
* document ;
* fuite ;
* enquête ;
* déclaration officielle ;
* rumeur.

La source influence la crédibilité.

---

# 5. Les médias

Les médias sont des organisations spécialisées dans la diffusion d'informations.

Ils peuvent :

* publier des articles ;
* interviewer des joueurs ;
* réaliser des enquêtes ;
* publier des sondages ;
* vérifier des informations.

Les médias jouent un rôle essentiel dans la vie politique.

---

# 6. Les enquêtes

Une enquête permet de rechercher des informations.

Elle peut viser :

* une organisation ;
* un joueur ;
* une entreprise ;
* une institution.

Une enquête demande :

* du temps ;
* des ressources ;
* parfois plusieurs personnes.

Toutes les enquêtes ne réussissent pas.

---

# 7. Les fuites

Certaines informations peuvent être transmises anonymement.

Une fuite peut :

* déclencher un scandale ;
* modifier une élection ;
* détruire une réputation.

La source n'est pas toujours connue.

---

# 8. Les rumeurs

Toutes les informations ne sont pas vraies.

Une rumeur circule librement.

Elle peut être :

* confirmée ;
* démentie ;
* oubliée.

Les joueurs doivent apprendre à distinguer le vrai du faux.

---

# 9. La désinformation

Certaines organisations peuvent volontairement diffuser de fausses informations.

La désinformation est une stratégie.

Elle comporte un risque.

Si elle est découverte :

* perte de réputation ;
* perte de crédibilité ;
* sanctions éventuelles.

---

# 10. Les preuves

Une accusation n'a pas toujours la même force.

Une preuve peut être :

* un témoignage ;
* un document ;
* un enregistrement ;
* un rapport d'enquête.

Plus les preuves sont solides, plus elles deviennent difficiles à contester.

---

# 11. La crédibilité

Chaque média possède une crédibilité.

Cette crédibilité évolue.

Elle dépend :

* de la qualité des enquêtes ;
* du nombre d'erreurs ;
* des manipulations découvertes.

Les joueurs choisissent naturellement les médias auxquels ils font confiance.

---

# 12. Les scandales

Un scandale apparaît lorsqu'une information importante devient publique.

Conséquences possibles :

* démission ;
* perte de réputation ;
* chute d'une organisation ;
* enquête parlementaire ;
* crise politique.

Les scandales constituent l'un des principaux moteurs du jeu.

---

# 13. Les archives

Toutes les grandes informations restent archivées.

Le serveur construit progressivement sa mémoire.

Exemples :

* grands procès ;
* scandales célèbres ;
* élections historiques ;
* grandes révélations.

Les archives racontent l'histoire du serveur.

---

# 14. L'équilibre

L'information est une arme.

Mais elle n'est jamais gratuite.

Obtenir une information importante demande :

* du temps ;
* des relations ;
* des ressources ;
* parfois des risques.

Le joueur doit constamment choisir entre révéler immédiatement une information ou attendre le moment le plus opportun.

---

# 15. Philosophie

Le jeu ne récompense pas uniquement celui qui possède le pouvoir.

Il récompense également celui qui comprend ce que les autres ignorent.

Dans Influence, une simple information peut faire tomber un gouvernement, sauver une entreprise ou déclencher une révolution.

Les joueurs ne se battent pas seulement pour contrôler des territoires ou des richesses.

Ils se battent pour contrôler ce que les autres croient.
