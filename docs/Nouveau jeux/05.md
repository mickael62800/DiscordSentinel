# Game Design Document

# Partie 5 – Les Organisations

---

# 1. Vision

Les organisations sont les véritables acteurs du monde.

Les joueurs les créent.

Les joueurs les dirigent.

Les joueurs les détruisent.

Mais les organisations peuvent survivre à leurs fondateurs.

Une organisation possède sa propre identité, sa réputation, son histoire et ses ambitions.

---

# 2. Pourquoi des organisations ?

Le jeu repose sur une idée simple :

> Les individus possèdent du pouvoir.

> Les organisations multiplient ce pouvoir.

Une personne seule peut influencer.

Une organisation peut changer le monde.

---

# 3. Les grands types d'organisation

Le jeu distingue plusieurs familles.

Chaque famille possède un rôle différent dans la société.

---

## Entreprises

Objectif :

Créer de la richesse.

Exemples :

* banque
* industrie
* commerce
* transport
* technologie

Une entreprise peut :

* recruter
* investir
* signer des contrats
* financer des projets
* sponsoriser des campagnes

---

## Partis politiques

Objectif :

Obtenir le pouvoir.

Ils présentent des candidats.

Proposent des lois.

Mènent des campagnes.

Tentent de gouverner le serveur.

---

## Médias

Objectif :

Contrôler l'information.

Ils publient :

* articles
* enquêtes
* interviews
* sondages

Ils peuvent révéler des scandales... ou en fabriquer.

---

## Syndicats

Objectif :

Défendre les intérêts d'un groupe.

Ils peuvent :

* organiser des grèves
* négocier
* faire pression sur le gouvernement

---

## Organisations secrètes

Objectif :

Influencer le monde sans être visibles.

Exemples :

* mafia
* réseau d'espions
* société secrète

Leur existence peut rester cachée.

---

# 4. Création d'une organisation

Créer une organisation doit être une décision importante.

Le fondateur choisit :

* le nom ;
* le type ;
* une devise ;
* un emblème ;
* une description ;
* les premiers dirigeants.

La création coûte des ressources afin d'éviter la prolifération.

---

# 5. Structure interne

Chaque organisation possède une hiérarchie.

Exemple :

Fondateur

↓

Dirigeants

↓

Responsables

↓

Membres

↓

Recrues

Les permissions sont gérées automatiquement par le bot.

---

# 6. Le recrutement

Les organisations recrutent librement.

Mais chaque recrutement représente un risque.

Plus une organisation grandit :

* plus elle devient puissante ;
* plus elle attire les espions ;
* plus elle devient difficile à gérer.

La croissance n'est jamais gratuite.

---

# 7. Réputation

Chaque organisation possède sa propre réputation.

Une entreprise peut être :

Très appréciée

ou

Détestée.

Un média peut être :

Très crédible

ou

Connu pour diffuser de la propagande.

Cette réputation influence directement les réactions des joueurs.

---

# 8. Influence collective

Les organisations possèdent leur propre influence.

Elle dépend notamment :

* du nombre de membres ;
* de leur réputation ;
* des postes qu'ils occupent ;
* des réussites de l'organisation.

Une organisation peut devenir plus influente que n'importe quel joueur.

---

# 9. Trésorerie

Les organisations disposent d'un budget indépendant.

Cette trésorerie sert à :

* financer des projets ;
* rémunérer des membres ;
* acheter des services ;
* investir ;
* lancer des campagnes.

Le patrimoine appartient à l'organisation.

Pas au dirigeant.

---

# 10. Histoire

Chaque organisation possède ses archives.

On peut consulter :

* sa date de création ;
* ses anciens dirigeants ;
* ses succès ;
* ses défaites ;
* les lois proposées ;
* les scandales.

Les archives deviennent progressivement la mémoire du serveur.

---

# 11. Vie d'une organisation

Une organisation peut :

naître ;

grandir ;

fusionner ;

se diviser ;

changer de dirigeant ;

faire faillite ;

être dissoute.

Le jeu doit permettre ces évolutions naturellement.

---

# 12. Leadership

Le dirigeant ne possède pas un pouvoir absolu.

Selon les statuts de l'organisation, il peut être :

élu ;

nommé ;

coopté ;

désigné par le fondateur.

Chaque organisation choisit son propre mode de gouvernance.

---

# 13. Relations entre organisations

Les organisations peuvent :

* signer des alliances ;
* conclure des partenariats ;
* entrer en concurrence ;
* déclarer un boycott ;
* fusionner ;
* rompre leurs accords.

Le monde devient un réseau de relations.

---

# 14. Dissolution

Une organisation peut disparaître.

Mais elle ne disparaît jamais des archives.

Même après plusieurs saisons, son histoire reste consultable.

Les anciennes organisations deviennent des éléments du patrimoine du serveur.

---

# 15. Philosophie

Les joueurs construisent des organisations.

Les organisations construisent la société.

Le véritable pouvoir ne réside pas uniquement dans les individus, mais dans leur capacité à créer des structures capables de survivre à leur propre carrière.

Une grande organisation doit devenir un symbole.

Un nom que les nouveaux joueurs découvriront dans les archives et reconnaîtront immédiatement.
